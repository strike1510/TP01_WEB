Exercice 5 : QR code + marker Hiro

Ce QR code redirige vers l'URL GitHub Pages du projet (à modifier ci-dessous une fois publié).

Instructions :

  1. Publiez le projet sur GitHub Pages.
  2. Remplacez GITHUB_PAGES_URL ci-dessous par votre URL réelle.
  3. Scannez le QR code avec l'appareil photo du téléphone → ça ouvre le site.
  4. Une fois le site (exercice2.html ou exercice3.html) ouvert, pointez la caméra du navigateur vers ce même QR code → le marqueur Hiro au centre est détecté et la boîte AR apparaît.
